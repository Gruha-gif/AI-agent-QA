# Закладки - создание закладки

## Назначение

Пользователь может сохранять закладки в личном списке, чтобы вернуться к нужному материалу позже.

## Функциональные требования

**FR-1.** Поле «Название» обязательно для создания закладки.

**FR-2.** Перед проверкой пробелы в начале и в конце названия удаляются. Пробелы внутри названия не допускаются. После удаления пробелов название может содержать только латинские буквы от a до z и от A до Z. Длина считается в символах Unicode после удаления пробелов и должна быть от 3 до 20 символов включительно.

**FR-3.** При корректном названии закладка создаётся и отображается первой в списке закладок пользователя. Список отсортирован по времени создания: сначала новые. Время создания определяет сервер.

**FR-4.** При пустом, слишком коротком, слишком длинном названии или при наличии недопустимых символов создание закладки блокируется и под полем «Название» показывается сообщение «Некорректное название закладки». Текст сообщения одинаковый для всех причин некорректности.

**FR-5.** Название закладки уникально в пределах списка пользователя без учёта регистра: названия «Alpha» и «alpha» считаются одинаковыми. Удалённые закладки при проверке уникальности не учитываются. При попытке создать закладку с уже существующим названием создание блокируется и показывается сообщение «Закладка с таким названием уже существует».

**FR-6.** Один пользователь может хранить не более 50 неудалённых закладок. При попытке создать 51-ю закладку создание блокируется и показывается сообщение «Достигнут лимит закладок».

## Ограничения

- создавать закладки может только авторизованный пользователь;
- неавторизованный пользователь видит экран входа и не может открыть форму создания закладки;
- механизм входа и работа с сессией в объём не входят: предполагается, что пользователь либо уже авторизован, либо не имеет активной сессии;
- функциональность доступна на платформе Android;
- сетевые ошибки и работа в офлайн-режиме в текущий объём не входят: при проверке предполагается стабильное соединение.

## Критерии приёмки

- закладка с корректным уникальным названием создаётся и становится первой в списке;
- некорректное название не создаёт закладку и показывает сообщение «Некорректное название закладки»;
- повтор названия без учёта регистра не создаёт дубликат и показывает сообщение «Закладка с таким названием уже существует»;
- 51-я закладка не создаётся и показывает сообщение «Достигнут лимит закладок».
